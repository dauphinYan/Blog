## 实施计划

### 背景说明
两个 UE 专区页面 import 的 `src/data/unreal-cpp.ts` 目前**已丢失**（写死的 `unrealCppTree` 目录树就在该文件中），当前状态构建会直接报错。因此本次会重建该数据模块，并把目录树改为**从内容文件自动生成**，同时完成路由调整。

### 1. 重建 `src/data/unreal-cpp.ts`（目录自动生成）
- `articleUrlSlug(id)`：集合 id（如 `containers/tarray.md`）→ 去掉 `.md` 后缀（`containers/tarray`）。
- `knowledgeBasePath = '/article/unreal-engine/cpp'`，`knowledgeUrl(slug)` 生成文章链接。
- 新增 `buildKnowledgeTree(entries)`：按集合 id 的路径段自动构建层级树——叶子节点为每篇文章（标题/描述/order 来自 frontmatter），目录节点为 md 所在子目录（标题由目录名自动美化，如 `reflection-system` → `Reflection System`），排序取子节点最小 order；`flattenKnowledgeTree` 输出带 depth 的扁平列表供侧边栏渲染。新增文章/目录时侧边栏自动更新。

### 2. 路由调整（移动页面文件）
- `src/pages/unreal-engine/cpp/[...slug].astro` → `src/pages/article/unreal-engine/cpp/[...slug].astro`，文章 URL 变为 `/article/unreal-engine/cpp/<slug>/`；修正相对 import。
- `src/pages/blog/[slug].astro` → `src/pages/article/blog/[slug].astro`，博客 URL 变为 `/article/blog/<slug>/`；修正相对 import。
- 专区首页保留在 `/unreal-engine/cpp/` 不动。

### 3. 更新页面引用
- `src/pages/index.astro:31`：博客卡片链接 `/blog/${post.id}/` → `/article/blog/${post.id}/`（UE 专区入口不变）。
- 专区两个页面改用 `buildKnowledgeTree` 渲染侧边栏（未发布条目显示为纯文本，逻辑保持现状），文章链接与面包屑自动指向新路径。

### 4. 验证
- `npm run build` 通过，检查产物中生成 `/article/unreal-engine/cpp/**`、`/article/blog/**` 页面。
- 用浏览器访问 dev server，验证专区首页目录树、文章页侧边栏高亮、博客文章新路径均可正常打开。
