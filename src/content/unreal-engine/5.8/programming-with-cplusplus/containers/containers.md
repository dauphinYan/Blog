# 虚幻引擎中的容器

虚幻引擎提供了多种容器类来存储和管理数据集合。这些容器经过优化，具有高性能和内存效率。

## 章节目录

- [TArray：数组](tarray.md) - TArray 存储相同类型元素的序列。
- [TMap](tmap.md) - TMap 由两种类型定义：键类型和值类型，以关联对的形式存储在映射中。
- [TSet](tset.md) - TSet 是一种快速容器类，用于在顺序无关紧要的情况下存储（通常）唯一的元素。
