# Internationalization

The homepage supports Simplified Chinese (`zh-CN`) and English (`en`). Chinese is served from the root path and English is served from `/en/`. Both routes render their locale statically, including when JavaScript is unavailable.

All localized copy is maintained in `src/content/profile.ts` under `translations`. The Chinese and English structures must remain aligned. This includes page metadata, navigation, profile content, anime and work showcase text, image descriptions, and accessibility labels.

Rendered copy uses `data-i18n`; translated `aria-label` and `alt` attributes use `data-i18n-aria-label` and `data-i18n-alt`. `src/components/Nav.astro` reads the locale from the current route, updates metadata, and switches between the root and `/en/` routes while preserving an in-page hash.

When adding a new localized element, add matching values for both locales, annotate the rendered element with the appropriate translation key, then run `npm run check` and `npm run build`.
